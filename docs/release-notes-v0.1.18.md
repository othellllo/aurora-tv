# Aurora TV v0.1.18

桌面端侧边栏换源、搜索保留、片头片尾时间戳。

## 桌面 / Windows

- **右侧播放源侧边栏**：
  - 列出全部内置 + 配置 CMS 站点，点击立即切换；
  - 下方列出聚合源，也可直接切换；
  - 高亮当前站点，加载时显示状态点；
  - 仅桌面/Windows 显示，手机和电视不占空间。
- **去掉画面正中央的暂停图标**：鼠标移动不再出现大暂停按钮，播放/暂停用底部控制条。
- 搜索：
  - 搜索词和结果不再因打开详情/关闭搜索而丢失；
  - 从搜索结果打开详情，返回后回到原来的结果页（不是首页）。

## 片头 / 片尾时间戳

- 播放器控制条新增「片头」「片尾」按钮：
  - 播到片头结束处点「片头」，记录当前时间；
  - 播到片尾开始处点「片尾」，记录当前时间。
- 设置 → 播放 也可手动填秒数。
- 行为：
  - 片头：播放到该时间会自动跳过（每集一次）；
  - 片尾：播放到该时间自动下一集（开启自动连播时）；
  - 时间线显示绿色片头、黄色片尾标记。
- 标记当前集不会立刻触发跳过，避免误跳。

## 兼容

- 电视 legacy 包（Android 5.x）继续提供；
- 手机手势、返回键、播放历史、同步、打赏通道保持不变。
